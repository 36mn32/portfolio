# Mechanical Engineering Technology Portfolio

A responsive, static portfolio website with pages for Home, About Me, Projects, Skills, and Contact.

## View locally

Open `index.html` in a web browser. The site uses plain HTML and CSS and does not require a build step or dependencies.

## Personalize

- Replace the About Me placeholder with your introduction.
- Update the three project cards and replace their illustrations in `images/` with project photos or renders.
- Adjust the skills and proficiency labels to match your experience.
- Add your preferred contact information on the Contact page. The site has no backend, so it does not include a message-sending form.
